YC-7ZIP

网页端压缩解压 · 直读 NAS 文件 · 支持分卷
>

在浏览器里管理 7z / ZIP / RAR / TAR / GZ / XZ / ISO 等格式， 直接读写 NAS 上的文件，不需要先把文件上传一遍。 支持分卷压缩与分卷解压——选中任意一卷即可解压，程序自动收集其余分卷。

下载

Docker Compose 推荐

多架构镜像，x86_64 与 ARM64 都能用；镜像内自带官方 7-Zip，无需另装。 配置文件里只有两行要改：要操作的目录与版本。

# 1. 下载 docker-compose.yml
# 2. 打开它，把这一行换成你要操作的 NAS 目录
#      - /vol1/1000:/share
# 3. 启动
docker compose up -d

# 升级：把 image 那行的版本改掉，然后
docker compose pull && docker compose up -d
下载 docker-compose.yml Docker Hub
路径要点：容器能看到的路径 = compose 里挂进去的路径。应用的 / 是 容器自己的根，不是 NAS 的根——数据在哪个卷上，就把那个卷挂进来， 并把容器内的路径写进 YC7ZIP_ALLOW_ROOTS。

飞牛 fnOS 应用包 .fpk

装好后有两个入口：应用列表里的 YC-7ZIP 图标，以及文件管理器里 对压缩包右键 →「打开方式」→ YC-7ZIP 压缩解压。 

# 到「应用中心 → 手动安装」选择下载好的 .fpk 文件
# 不需要 Docker：包里自带 yc7zip 与官方 7-Zip（x86_64 与 arm64 各一份）
下载 yc7zip.fpk fpk 源码
安装前必读：fnpack 打包的 manifest 只接受 semver，所以 fpk 内的版本号是 （对应项目版本 ）。 fpk 与 Docker 无关，装好后由应用包自己拉起进程，数据放在应用的 TRIM_PKGVAR（升级会保留）。

说明

RAR 只能解压。 RAR 的压缩算法未开放授权，任何第三方软件都无法生成 .rar 文件。

为什么单独做一个。 飞牛 fnOS 自带的压缩功能没有分卷选项，而分卷恰恰是把大文件投递到网盘、 微信、FAT32 移动盘时最常用的能力。

权限。 -allow-root 是唯一的安全边界，只有列在这里的目录能被读写。 飞牛应用包默认放开所有挂载进来的卷，并把端口只绑在 127.0.0.1， 访问必须经过飞牛的登录态。
